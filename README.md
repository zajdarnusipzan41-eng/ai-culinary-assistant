# 🍳 AI Culinary Assistant

AI Culinary Assistant is a web application that generates delicious recipes based on the ingredients provided by the user using Google's Gemini AI.

---

## 📖 About

This project allows users to enter available ingredients and receive AI-generated recipes instantly.

The application consists of:

- ⚛️ React frontend
- 🐍 Python Flask backend
- 🤖 Google Gemini API integration

---

## ✨ Features

- Generate recipes using AI
- Enter your own ingredients
- Fast AI responses
- Modern and responsive interface
- REST API with Flask
- Easy to use

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/ai-culinary-assistant.git
```

### Backend

```bash
cd backend

pip install -r requirements.txt

python app.py
```

Create a `.env` file and add your Gemini API key:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### Frontend

```bash
cd frontend

npm install

npm start
```

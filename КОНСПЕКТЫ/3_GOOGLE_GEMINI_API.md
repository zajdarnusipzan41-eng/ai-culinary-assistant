# 🤖 КОНСПЕКТ 3: Google Gemini API

## 📚 Что такое Google Gemini?

**Gemini** = AI модель от Google, которая может:
- Генерировать текст
- Отвечать на вопросы
- Анализировать информацию
- Создавать креативный контент

**В нашем проекте:** Используем Gemini для генерации рецептов! 🍳

---

## 🔑 Как получить API ключ?

### Шаг 1: Откройте Google AI Studio
```
Перейдите на: https://aistudio.google.com/app/apikey
```

### Шаг 2: Нажмите "Create API Key"
- Выберите проект (или создайте новый)
- Копируйте ключ

### Шаг 3: Сохраните в .env файл
```
GEMINI_API_KEY=abc123def456xyz789...
```

**Важно:**
- ✅ Копируйте ключ в `.env` файл
- ❌ НИКОГДА не загружайте ключ на GitHub
- ❌ Не делитесь ключом с другими!

## 💻 Как подключить Gemini в коде?

### Шаг 1: Установить библиотеку
```bash
pip install google-generativeai
```

### Шаг 2: Импортировать и настроить
```python
import google.generativeai as genai
from config import config

# Устанавливаем API ключ
genai.configure(api_key=config.GEMINI_API_KEY)

# Создаём модель
model = genai.GenerativeModel("gemini-pro")
```

### Шаг 3: Отправить запрос
```python
# Создаём промпт (инструкция для AI)
prompt = "Дай рецепт омлета"

# Отправляем запрос
response = model.generate_content(prompt)

# Получаем ответ
print(response.text)  # "Омлет — это блюдо из яиц..."
```

## 🎯 Что такое Промпт (Prompt)?

**Промпт** = инструкция/текст, который мы отправляем AI

### Плохой промпт:
```
"Рецепт"
```
**Результат:** Неясно, что AI должна делать

### Хороший промпт:
```
"Ты профессиональный шеф-повар.
Дан список ингредиентов: яйцо, масло, мука
Предложи 2-3 рецепта с пошаговыми инструкциями"
```
**Результат:** AI понимает, что делать

---

## 📝 Структура промпта

### 1️⃣ **Роль (Role)**
```
"Ты профессиональный шеф-повар..."
"Ты знающий кулинар..."
"Ты эксперт по питанию..."
```

### 2️⃣ **Задача (Task)**
```
"Предложи рецепты..."
"Ответь на вопрос..."
"Найди замену для..."
```

### 3️⃣ **Контекст (Context)**
```
"Дан список ингредиентов: яйцо, масло"
"Вопрос пользователя: Как готовить яйцо?"
```

### 4️⃣ **Требования (Requirements)**
```
"Укажи время приготовления"
"Дай 3 варианта"
"Ответ должен быть кратким"
```

### 📋 Полный пример:
```python
prompt = """
Ты профессиональный шеф-повар.
Дан список ингредиентов: яйцо, масло, мука

Предложи 2-3 рецепта:
1. Название
2. Время приготовления
3. Пошаговые инструкции
4. Сложность (легко/средне/сложно)
"""
```

---

## 🔄 Жизненный цикл запроса к Gemini

```
1. Пользователь вводит ингредиенты
   ["яйцо", "масло", "мука"]
                    ↓
2. Backend создает промпт
   "Ты шеф-повар. Дай рецепты для: яйцо, масло, мука"
                    ↓
3. Отправляем на Google Gemini API
   POST https://generativelanguage.googleapis.com/...
   Headers: { "Authorization": "Bearer API_KEY" }
   Body: { "prompt": "Ты шеф-повар..." }
                    ↓
4. Google Gemini обрабатывает
   (AI модель думает и создает ответ)
                    ↓
5. Google возвращает ответ
   {
     "text": "1. Омлет - 5 минут...\n2. Блины - 10 минут..."
   }
                    ↓
6. Backend получает ответ
                    ↓
7. Backend отправляет Frontend
                    ↓
8. Frontend показывает рецепты пользователю
```

## ⚙️ Параметры модели

В `config.py` есть параметры для настройки поведения AI:

```python
class Config:
    MODEL_NAME = "gemini-pro"  # Имя модели
    TEMPERATURE = 0.7          # 0 = точный, 1 = творческий
    MAX_OUTPUT_TOKENS = 1000   # Максимальная длина ответа
```

### 🌡️ TEMPERATURE (Температура)

```
0.0 = Очень точный, повторяющийся
      "1 + 1 = 2" → Всегда "2"
      
0.5 = Сбалансированный (по умолчанию)
      Хороший компромисс
      
1.0 = Очень творческий, разный
      "1 + 1 =" → Может ответить "2", "два", "sum of 1 and 1" и т.д.
```

**Для нашего проекта (рецепты):** 0.7 идеально
- Не слишком творческий (не будет придумывать странные рецепты)
- Не слишком скучный (будет разнообразить предложения)

## 🎓 Как AI работает внутри?

**Упрощенно:**

```
Промпт (текст) 
   ↓
Gemini превращает текст в числа (embeddings)
   ↓
AI модель обрабатывает числа
   ↓
Выпускает вероятности для следующего слова
   ↓
Выбирает слово с наибольшей вероятностью
   ↓
Повторяет для каждого слова
   ↓
Получается: "Яйцо можно готовить несколькими способами..."
```

**Результат:** Текст, который выглядит как написанный человеком! 🤖

## 💡 Ключевые концепции

| Термин | Что это |
|--------|--------|
| **API** | Application Programming Interface - способ общения с сервисом |
| **API Key** | Секретный ключ для доступа к API |
| **Prompt** | Инструкция/текст для AI |
| **Model** | AI модель (gemini-pro) |
| **Temperature** | Параметр творчества (0 = точный, 1 = творческий) |
| **Token** | Условная единица текста (примерно 4 символа = 1 token) |
| **Response** | Ответ от AI |

---

## ✅ Запомните

1. **Gemini** = AI от Google для генерации текста
2. **API Key** = пароль для доступа (никому не показывать!)
3. **Prompt** = то, что вы пишете AI
4. **Response** = то, что возвращает AI
5. **Temperature** = контролирует творчество AI
6. **JSON** = формат передачи данных

# 🐍 КОНСПЕКТ 1: Backend Архитектура

## 📚 Что такое Backend?

**Backend** = "задняя часть" приложения, которая работает на сервере.

Думайте о ресторане:
- **Frontend** = официант (видит клиент, принимает заказы)
- **Backend** = кухня (обрабатывает заказы, готовит)
- **API** = связь между официантом и кухней

---

## 🔑 Что делает каждый файл?

### 1️⃣ **app.py** - Сердце Backend

```python
# Это главный файл, который запускает сервер
app = Flask(__name__)  # Создаем Flask приложение
app.run()              # Запускаем сервер на порту 5000
```

**Что в нём:**
- Создание Flask приложения
- API endpoints (маршруты)
- Обработка HTTP запросов

---

### 2️⃣ **config.py** - Настройки

```python
# Тут хранятся все настройки приложения
GEMINI_API_KEY = "ваш-ключ-api"
DEBUG = True
PORT = 5000
```

**Зачем отдельный файл?**
- Легко менять настройки
- Безопасно хранить секреты
- Один файл для разработки, другой для production

## 🔄 Как всё работает вместе?

### Сценарий: Пользователь вводит ингредиенты

```
1. Пользователь в Frontend вводит: ["яйцо", "масло"]
                    ↓
2. Frontend отправляет HTTP POST запрос на backend:
   POST /api/recipes
   Body: { "ingredients": ["яйцо", "масло"] }
                    ↓
3. Backend (app.py) получает запрос на маршруте /api/recipes
                    ↓
4. app.py вызывает RecipeManager.get_recipes_by_ingredients()
                    ↓
5. RecipeManager вызывает GeminiService.generate_recipes()
                    ↓
6. GeminiService отправляет запрос к Google Gemini API:
   "Дай рецепты для: яйцо, масло"
                    ↓
7. Google Gemini возвращает рецепты
                    ↓
8. GeminiService возвращает результат RecipeManager
                    ↓
9. RecipeManager возвращает результат app.py
                    ↓
10. app.py отправляет HTTP ответ на Frontend
    Response: {
      "success": true,
      "recipes": "Омлет, блины, ..."
    }
                    ↓
11. Frontend получает ответ и показывает рецепты пользователю
```

## 📡 API Endpoints (маршруты)

Это URL адреса, на которые можно отправлять запросы:

| Метод | Endpoint | Что делает |
|-------|----------|-----------|
| POST | `/api/recipes` | Получить рецепты по ингредиентам |
| POST | `/api/question` | Задать вопрос AI кулинару |
| POST | `/api/substitute` | Получить замену ингредиента |
| POST | `/api/favorites` | Добавить рецепт в избранное |
| GET | `/api/favorites` | Получить избранные рецепты |
| GET | `/api/health` | Проверить, работает ли сервер |

## 🚀 Как запустить Backend?

### Шаг 1: Установить Python зависимости
```bash
cd backend
pip install -r requirements.txt
```

### Шаг 2: Создать .env файл
```bash
# Скопируйте .env.example в .env
cp .env.example .env

# Откройте .env и добавьте ваш Google Gemini API key
# GEMINI_API_KEY=abc123...
```

### Шаг 3: Запустить сервер
```bash
python app.py
```

**Результат:**
```
🍳 AI Culinary Assistant Backend запущен!
📍 http://localhost:5000
```

## ✅ Как проверить, что Backend работает?

### Метод 1: Через браузер
Откройте: http://localhost:5000/api/health

Должно быть: `{"status": "ok", "message": "Server is running"}`

### Метод 2: Через curl (в терминале)
```bash
curl http://localhost:5000/api/health
```

### Метод 3: Через Postman (приложение)
1. Скачайте Postman
2. Создайте GET запрос на http://localhost:5000/api/health
3. Отправьте и увидите ответ

## 🎯 Ключевые концепции

| Концепция | Объяснение |
|-----------|-----------|
| **Flask** | Фреймворк (набор инструментов) для создания веб-серверов на Python |
| **API** | Application Programming Interface - способ общения между частями |
| **Endpoint** | URL адрес, на который можно отправлять запросы |
| **Request** | Запрос, который отправляет Frontend на Backend |
| **Response** | Ответ, который Backend отправляет обратно |
| **JSON** | Формат данных для передачи (как словарь в Python) |
| **CORS** | Разрешение на запросы с других доменов |

---

## 💡 Запомните

1. **Backend** = сервер, который обрабатывает запросы
2. **Flask** = инструмент для создания backend на Python
3. **API** = способ общения frontend и backend
4. **Endpoints** = маршруты, по которым приходят запросы
5. **JSON** = формат данных для передачи
